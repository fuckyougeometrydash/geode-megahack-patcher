# Mega Hack Patcher

Script to download and patch Mega Hack.

## Usage

### Patch only

```bash
python script.py
```

### Patch and install

```bash
python script.py --install <path-to-GeometryDash.exe>
```

## Parameters

| Parameter                    | Description                           |
| ---------------------------- | ------------------------------------- |
| `--install`                  | Installs the patched `.geode`.        |
| `<path-to-GeometryDash.exe>` | Path to the Geometry Dash executable. |

## Example

```cmd
python script.py --install "C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash\GeometryDash.exe"
```

The path must point directly to `GeometryDash.exe`.
